# Nutrición Diaria - RemNote Plugin

Este plugin de RemNote permite registrar tu peso diario y las comidas directamente dentro de tus Daily Documents, calculando la meta calórica diaria y haciendo seguimiento del consumo mediante fórmulas nutricionales estándar (Mifflin-St Jeor).

## Características principales
*   **Registro de peso**: Recuerda y sugiere el peso del día anterior.
*   **Estimación de comidas**: Estima calorías basándose en lenguaje natural.
*   **Configuración personal**: Configura sexo, altura, fecha de nacimiento, actividad física y déficit deseado.
*   **Persistencia local y sincronizada**: Todo se sincroniza y almacena de forma nativa en RemNote.
*   **Diseño minimalista**: Integrado completamente con el modo oscuro y claro de RemNote.
